# DevLife

Projeto DevLife - Organizador pessoal e profissional.

## Stack
- Monorepo com Turborepo + pnpm
- Backend: Node.js + Fastify + Prisma
- Web: Next.js + Tailwind
- Mobile: React Native + Expo
- Banco: PostgreSQL

## Requisitos
- Node.js 20+
- PNPM 8+
- Docker (opcional)

## Instalação
```bash
pnpm install
